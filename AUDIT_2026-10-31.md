# Audit — 31 October 2026

## Fixed
IPv6 inputs are rejected by this IPv4-only scanner. Noncontiguous subnet masks are rejected. Local subnet discovery reads the real interface prefix (Linux ip JSON, ifconfig fallback, Windows adapter-local address/mask pairing); no external probe or guessed /24 fallback is used. Explicit IPv4-address shorthand intentionally remains /24 for compatibility. Scans above 4096 hosts are rejected before worker allocation. Failed TTL-expired responses are not counted as hosts, macOS uses millisecond timeout units, invalid CLI requests fail with a nonzero status, and interruption cancels queued pings.

## Executed
13 standard-library unittest cases pass. They mock ping/interface commands and cover Windows/Linux/macOS command handling, parsing, masks, scan bounds, reachability result handling, cancellation and CLI errors. Ruff syntax/undefined-name checks pass.

## Limits
No external network was scanned. Real Windows/macOS execution and permissions-dependent ICMP behaviour still need device testing. The new CI matrix is configured for those platforms; it has not been run locally.
